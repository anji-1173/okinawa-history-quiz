# しまの記憶｜沖縄歴史クイズ

沖縄の歴史を、琉球王国から戦前・戦後・アメリカ統治・日本復帰・海洋博・九州・沖縄サミットまで、時代別クイズと地図で学ぶウェブアプリです。

## 現在の実装範囲

- 8つの時代を見渡すタイムライン
- 「沖縄県の成立から沖縄戦」初級・中級・上級、各10問（計30問）
- 「琉球王国の成立と交易」初級・中級・上級、各10問（計30問）
- 「薩摩侵攻後の王国」初級・中級・上級、各10問（計30問）
- 「戦後の再出発」初級・中級・上級、各10問（計30問）
- 「米国統治と琉球政府」「日本復帰と制度転換」「海洋博と観光・振興」「サミットから現代へ」それぞれ各級10問（計120問）
- 国土地理院「地球地図日本」を加工した、本島周辺図と沖縄県全体図
- 島田叡、大田實、対馬丸・和浦丸・暁空丸、USS Bowfinの問題
- 世界遺産9資産、戦争遺跡、慰霊・資料施設、学童疎開船航路のクリック式マップ
- Pacific Fleet Submarine Museumと対馬丸記念館の資料比較
- 問題ごとの出典リンク、進捗のブラウザ保存、キーボード操作

全8時代 × 3難易度 × 各10問の計240問を収録済みです。各コースの選択肢は挑戦ごとに並べ替えられ、途中の問題からも参加できます。

## 2026-09-25 完成時点

残り80問を追加し、全24コースを公開。年表と出典を追加し、すべてのコースで途中参加・全問回答・採点・保存を自動テストしています。上級の資料A・Bは原文引用ではなく、出典をもとにした学習用の要約です。

成績は時代・難易度別にv2キーで保存します。旧v1記録には時代情報がないため、自動で時代を割り当てず元のキーに保持し、新しい完了数には加算しません。ブラウザや公開ドメインが異なる場合、記録は共有されません。

## 2026-09-17 引き継ぎ

当時の区切りは「薩摩侵攻後の王国・上級編」と「戦後の再出発・初級編」まででした。現在の収録状況は上記を参照してください。

地図は `scripts/generate-okinawa-map.mjs` で再生成できます。国土地理院「地球地図日本」の行政界データを dataofjapan/land がGeoJSON化した資料から、沖縄県の101ポリゴンを抽出しました。上下それぞれの図の中では位置・向き・縮尺を統一し、経度方向を中央緯度の余弦で補正しています。海岸線は原資料の縮尺・作成時点に基づく簡略表示で、現況測量図ではありません。出典リンクはトップ図の下に表示しています。

## 編集方針

- すべての問題に公的資料または施設公式資料を紐づけます。
- 事実・解釈・当事者の立場を分けます。
- 戦争、犠牲、慰霊を速さや派手な演出の対象にしません。
- 立入禁止・内部非公開の戦争遺跡へ誘導しません。
- Bowfinは「日米の見方」と一般化せず、二つの施設の使命と資料の焦点を比較します。

## 技術

React / TypeScript / Vite / MapLibre GL JS。GitHub Actionsでテストとビルドを行い、`main`更新時にGitHub Pagesへ配信する構成です。
